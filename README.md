# E-Commerce Sales Analysis Dashboard

## Project Overview

This project demonstrates an end-to-end **Data Analytics** workflow
using **MySQL, Python, and Power BI**. The objective is to analyze
e-commerce sales data, identify business trends, and build an
interactive dashboard.

## Tech Stack

-   MySQL
-   Python (Pandas, Matplotlib)
-   Power BI
-   Excel
-   GitHub

## Dataset

### Customers

customer_id, customer_name, gender, age, city, state

### Products

product_id, product_name, category, price, cost_price

### Orders

order_id, product_id, customer_id, order_date, quantity, payment_mode

## Features

-   SQL business queries
-   Data cleaning with Python
-   Sales and Profit analysis
-   KPI calculations
-   Interactive Power BI dashboard
-   Charts and reports

## KPIs

-   Total Sales
-   Total Profit
-   Total Orders
-   Total Customers
-   Total Products
-   Total Quantity

## Dashboard

-   Monthly Sales Trend
-   Sales by Category
-   Top Products
-   Top Customers
-   Payment Mode Analysis
-   Sales by State
-   Gender Analysis
-   Interactive Filters
